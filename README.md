# Задание:
## Оформить страницу из ЛР №1 с помощью внешнего CSS файла (style.css). Реализовать:
<ul>
  <li>Основной стиль – во внешнем файле; 1 элемент с inline стилями; 1 правило во внутреннем блоке <style>.</li>
  <li> CSS переменные в :root для цветов и шрифтов</li>
  <li>Примеры позиционирования: static, relative, absolute.</li>
  <li>Состояния элементов: :hover, :active, :focus, :visited</li>
  <li> Контрастность текста не менее 4.5:1.</li>
</ul>

## Вариант 6. Тема «Любитель кино и сериалов».
Секцию «Проекты» оформите как сетку из 3 колонок (display: grid). При наведении на
карточку проекта добавляйте полупрозрачный оверлей и увеличивайте шрифт заголовка
внутри карточки. При :focus на кнопке отправки формы добавляйте красную рамку (цвет
премии «Оскар»). В переменных: основной – чёрный, акцент – золотой. Inline-стиль:
задайте font-weight: 700 для заголовка страницы в "header". Внутренний блок "style": стили
для "aside" (фиксированная ширина и фон).
